# Web

Next.js frontend for PDF Assistant.

- Upload PDFs and track their processing status
- Side-by-side PDF preview and chat
- Streaming answers with clickable citations that jump to the cited page
- Portuguese / English UI

```bash
cp .env.example .env.local
pnpm --filter web dev   # http://localhost:3000
```

See the [root README](../../README.md) for the full setup.
